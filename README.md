# Faza Portfolio

Hello everyone! 👋

I'm **Faza Syaquille Suny**, an Electrical Engineering graduate with an interest in **Cloud Engineering, Machine Learning, Web Development, IoT, Networking, and IT Support**.

This repository contains my personal portfolio website, built with React and Supabase. The website includes a public-facing portfolio and an admin dashboard for managing projects, certificates, and comments.

**Live Demo:** https://fazaporto.netlify.app/

---

## 🛠️ Tech Stack

This project is built using:

- **ReactJS** — Frontend framework
- **Vite** — Frontend build tool
- **Tailwind CSS** — Utility-first CSS framework
- **Supabase** — Backend services, database, authentication, storage, and realtime features
- **PostgreSQL** — Database
- **AOS** — Animate On Scroll library
- **Framer Motion** — Animation library
- **Lucide** — Icon library
- **Material UI** — React component library
- **SweetAlert2** — Alert and notification dialogs

---

## 👤 User Roles

| Role | Access |
|---|---|
| **Visitor (Public)** | View projects, certificates, and comments; submit comments |
| **Admin** | Login to dashboard; manage projects and certificates; manage comments |
